# 🎓 نظام المساعد التعليمي الذكي للمدارس العراقية

## Iraq Educational AI Assistant

نظام ذكي متكامل لمساعدة المعلمين والطلاب في المدارس الإعدادية العراقية، مدعوم بالذكاء الاصطناعي ومعالجة اللغة العربية.

---

## 🌟 المميزات الرئيسية

### 👨‍🏫 لوحة المعلم

- **📝 توليد خطط الدروس**: إنشاء خطط تدريسية تفصيلية بناءً على المنهج العراقي
- **❓ إنشاء الأسئلة بالذكاء الاصطناعي**: توليد اختبارات متنوعة (اختيار من متعدد، صح/خطأ، أكمل الفراغ)
- **📄 تصدير PDF**: تحويل الخطط والاختبارات لصيغة PDF جاهزة للطباعة
- **📤 معالجة الملفات**: استخراج النصوص من PDF وWord وTXT

### 👨‍🎓 لوحة الطالب

- **📅 خطة الدراسة الذكية**: جدولة مخصصة بناءً على موعد الامتحان والمواد
- **📖 تحليل صعوبة النصوص**: تقييم مستوى الصعوبة وتحديد الكلمات المعقدة
- **🔊 تحويل النص لصوت**: استماع للدروس عبر تقنية TTS

### 💻 مختبر الحاسوب

- **⏱️ اختبارات محددة بالوقت**: 100 سؤال تفاعلي مع عداد تنازلي
- **🎯 تكيف حسب الصف**: أسئلة متدرجة الصعوبة (رابع/خامس/سادس علمي)
- **📊 نتائج فورية**: ملاحظات تفصيلية وشرح للأجوبة

### 🔐 نظام المصادقة

- **🔑 تسجيل دخول آمن**: تشفير كلمات المرور بـ bcrypt
- **👥 أدوار المستخدمين**: معلم/طالب مع صلاحيات مخصصة
- **📈 لوحة التقدم**: إحصائيات استخدام مفصلة

## 🤖 الذكاء الاصطناعي والمعالجة اللغوية

### AI Models

1. **Primary**: OpenAI GPT (`gpt-5-mini`) — النموذج الأساسي للتوليد
2. **Secondary**: Google Gemini (`gemini-2.0-flash-lite`) — نموذج احتياطي عند تعذّر OpenAI
3. **Local Offline**: Qwen2.5-1.5B-Instruct (اختياري، ~3GB) — يُفعّل بـ `ENABLE_LOCAL_LLM=1`

### Arabic NLP Features

- **معالجة النصوص العربية** باستخدام CAMeL Tools
- **تحليل التشكيل والصرف**
- **استخراج الجذور والكلمات الرئيسية**
- **حساب TF-IDF** للمصطلحات العربية
- **إزالة Stop Words** المخصصة للعربية

> **ملاحظة**: المواد ذات المحتوى الرياضي والمنطقي المعقد (الرياضيات، الفيزياء، الكيمياء) ستُضاف في الإصدارات القادمة باستخدام نماذج استدلال متقدمة من OpenAI (مثل GPT-o1/o3) والنماذج المحلية المتخصصة.

## 🚀 التثبيت والإعداد

### الطريقة الأولى: باستخدام Conda (موصى بها)

#### 1. إنشاء البيئة

```bash
# إنشاء البيئة من environment.yml
conda env create -f environment.yml

# تفعيل البيئة
conda activate iraq-edu-ai
```

#### 2. التحقق من التثبيت

```bash
python --version  # يجب أن يظهر Python 3.11.x
pip list | findstr flask  # للتأكد من تثبيت Flask
```

---

### الطريقة الثانية: باستخدام Python venv

#### 1. إنشاء البيئة الافتراضية

```bash
# إنشاء البيئة
python -m venv venv

# تفعيل البيئة
# على Windows:
venv\Scripts\activate

# على Linux/Mac:
source venv/bin/activate
```

#### 2. تثبيت المكتبات

```bash
# تثبيت جميع التبعيات
pip install -r requirements.txt
```

#### 3. التحقق من التثبيت

```bash
pip list  # عرض جميع المكتبات المثبتة
```

## ⚙️ الإعداد الأولي

### 1. إعداد ملف البيئة

```bash
# نسخ ملف .env التجريبي
copy .env.example .env

# (على Linux/Mac: cp .env.example .env)
```

### 2. تحرير ملف `.env`

افتح الملف `.env` وأضف مفاتيح API:

```env
# إعدادات Flask
FLASK_SECRET_KEY=your-random-secret-key-change-this
FLASK_DEBUG=1

# الذكاء الاصطناعي الأساسي (OpenAI)
# احصل على المفتاح من: https://platform.openai.com/api-keys
OPENAI_API_KEY=sk-your-key-here

# الذكاء الاصطناعي الاحتياطي (Gemini)
# احصل على مفتاح مجاني من: https://aistudio.google.com/app/apikey
GEMINI_API_KEY=your-gemini-key-here

# تفعيل النموذج المحلي (اختياري)
ENABLE_LOCAL_LLM=0  # اضبط على 1 لتفعيل Qwen (~3GB)
```

### 3. إنشاء قاعدة البيانات

القاعدة ستُنشأ تلقائياً عند أول تشغيل في المجلد `instance/app.sqlite3`

## 🎯 أمثلة الاستخدام

### للمعلم

1. **إنشاء خطة درس**:

   - اذهب إلى "وضع المعلم"
   - املأ: المادة، الصف، العنوان، المدة
   - اضغط "إنشاء الخطة"
   - صدّر كـ PDF

2. **توليد اختبار**:
   - ارفع ملف الدرس (PDF/Word)
   - حدد عدد الأسئلة

1. **تحليل صعوبة النص**:

2. **إنشاء خطة دراسة**:
   - أدخل موعد الامتحان
   - حدد المواد والمواضيع
   - احصل على جدول مخصص

## 🔧 الحل للمشاكل الشائعة

### خطأ: "ModuleNotFoundError"

```bash
# تأكد من تفعيل البيئة
conda activate iraq-edu-ai  # أو
source venv/bin/activate

# أعد التثبيت
pip install -r requirements.txt
```

### خطأ: "Port 5000 already in use"

```bash
# غيّر المنفذ في run.py:
app.run(host="127.0.0.1", port=5001, debug=debug)
```

### خطأ: "OpenAI API error"

- تحقق من صحة `OPENAI_API_KEY` في `.env`
- تأكد من وجود رصيد في حسابك
- سيتحول النظام تلقائياً لـ Gemini أو NLP

### النموذج المحلي بطيء

- استخدم GPU إن أمكن
- قلل `max_new_tokens` في إعدادات Qwen
- أو اعتمد فقط على OpenAI/Gemini
